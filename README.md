# akshat-jain.me

The coming-soon page for Akshat Jain’s personal website, built with the Next.js App Router, TypeScript and Tailwind CSS.

## Local development

Use Node.js 20.9 or later.

```sh
npm ci
npm run dev
```

Open [localhost:3000](http://localhost:3000).

```sh
npm run lint
npm run typecheck
npm run build
npm start
```

The home page lives in `app/page.tsx`, site metadata in `app/layout.tsx`, and shared design tokens in `app/globals.css`. The typefaces are hosted with the app, with their licenses in `app/fonts/`.
